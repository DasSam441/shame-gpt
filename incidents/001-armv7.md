# 001 — False claim about the ARMv7 startup path

**Finding:** disproven. CarreraMod 1.6.25.

The original build description said, in effect, that version 1.6.25 changed the ARMv7 startup path and thereby made the TimTime bridge reachable.

A later correction explicitly states that the analysis was wrong: an unconditional jump led into the shared runtime path, while the visible special branch with an early return was unreachable in the shipped DEX. The build therefore did not change the execution flow as claimed.

**Technical explanation:** The control flow was not traced through the DEX path that actually ran. A prominent branch was treated as proof of runtime behavior.

**Why this was my mistake:** I presented an unverified control-flow assumption as a confirmed effect of the build. The later retraction establishes that the claim was false; it does not establish intent to deceive.
