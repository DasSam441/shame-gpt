# 012 — Overview of the CarreraMod ARMv7 crash series

This page used to compress many Android attempts into version ranges, which hid their individual outcomes and blurred attempts with confirmed causes. The documented failures now have separate reports: [1.6.18 hook deferral did not fix the original crash](042-1-6-18-post-login-hook-delay-did-not-fix-armv7-crash.md), [1.6.20 lost a required DEX while repackaging](043-1-6-20-dropped-classes5-dex.md), [1.6.22 falsely claimed Guest startup had no native intervention](044-1-6-22-guest-path-claim-was-false.md), [1.6.23 removed the known PLT guard](045-1-6-23-removed-needed-memset-guard.md), and [1.6.24 could silently miss guard installation](046-1-6-24-fire-and-forget-retries-never-installed-guard.md). The earlier 1.6.25 control-flow error is documented in [report 001](001-armv7.md); the later 1.6.53 failed attempt has its own source record but is not expanded here until its evidence is reviewed.

The project notes count twelve versions from 1.6.3 through 1.6.25 as attempts in a shared crash class. That count does not mean twelve independent root causes. The underlying ARMv7 tombstone and source notes are in the private CarreraMod repository.
