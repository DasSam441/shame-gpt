# 042 — CarreraMod 1.6.18 moved TimTime hooks but left the ARMv7 crash path intact

**What happened:** 1.6.18 deferred the TimTime post-login hooks, but the documented ARMv7 crash still occurred. Later 1.6.19 evidence localized the continuing fault to the original firmware UpdateFirmware.Run → memset path.\n\n**Technical explanation:** The 1.6.18 change targeted when TimTime hooks were installed from the Guest-login coroutine. It did not repair the original ARMv7 null memset GOT/PLT target. Those are separate paths; delaying one could not correct the other.\n\n**Why this was my mistake:** I treated a plausible timing change as a candidate remedy without separating the added TimTime hook path from the observed crash inside the original firmware update path.\n\n**Evidence and limits:** Private note docs/CARRERAMOD_1.6.19_ARMV7_FIRMWARE_CALLSITE.md says 1.6.18 left the known crash unchanged and cites the dump and tombstone. The 1.6.18 note records the deferred-hook change and says a device test was still needed. This report does not infer an unrecorded 1.6.18 APK test.
