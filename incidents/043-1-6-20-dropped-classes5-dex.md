# 043 — CarreraMod 1.6.20 lost classes5.dex during APK repackaging

**What happened:** 1.6.20 was blocked because Apktool repackaging omitted classes5.dex. The missing DEX contains TimTimeVehicleClient, required for pairing and manifest access.\n\n**Technical explanation:** Android multidex packages keep application classes across classes.dex and later DEX files. Omitting one removes every class defined only there. Here the lost fifth DEX removed core TimTime connectivity code even though the native ARMv7 patch itself was not the packaging failure.\n\n**Why this was my mistake:** I treated successful native patching and APK alignment/signing as sufficient packaging validation without verifying the complete DEX inventory against the known-good input.\n\n**Evidence and limits:** Private note docs/CARRERAMOD_1.6.20_ARMV7_MEMSET_PLT.md marks 1.6.20 blocked, identifies the missing DEX contents, and records that 1.6.21 repacked from the 1.6.19 structure while preserving all five DEX files. No claim is made that 1.6.20 was released to users.
